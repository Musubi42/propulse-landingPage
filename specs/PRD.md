## 1. Project Overview

### 1.1 Objectives
- Present Propulse as a movement-in-motion (not an established institution)
- Leverage LinkedIn momentum (50+ mentors, 400+ reactions) as social proof
- Clearly segment 3 audiences: Lycéens, Mentors, Lycées
- Communicate the emotional founder story and mission
- Drive conversions to 3 distinct CTAs with equal priority
- Establish strong visual identity using pen/paper/journey metaphor

### 1.2 Key Principles
- **100% gratuit** - Emphasized throughout
- **100% à distance** - Using intuitive internet tools
- **Movement, not institution** - Energy, authenticity, momentum
- **Warm & approachable** - Not corporate, relatable
- **Stats-driven** - Show the gap we're closing
- **Founder-story led** - Arthur & Hugo's journeys = credibility

## 2. Visual Identity System

### 2.1 Core Design Elements

#### **The Pen & Journey Metaphor**
- **Primary motif:** Hand-drawn pen line that traces a "journey" as user scrolls
- **Usage:**
  - Animated line that "writes" key stats as they appear
  - Connects milestone timeline sections
  - Subtle background element that gives sense of progression
  - NOT used as hard section dividers (too old-fashioned)

#### **The Paper & Ink Aesthetic**
- **Background:** Old aged paper color palette
  - Warm cream/beige tones (#FFF8E7, #F5EFE0, #FAF3E3)
  - Subtle paper texture (very light, not overwhelming)
  - Must remain professional, avoid "vintage overload"
  
- **Accent Colors:**
  - Primary: Deep navy blue (for text, CTAs) - #1E3A5F
  - Secondary: Warm green (for highlights, success) - #4A7C59
  - Accent: Burnt orange/terracotta (for "Fonce!" moments) - #C86430
  - Ensure high contrast for readability

#### **Polymorph Soft Dividers**
- Inspired by 1jeune1mentor.fr
- Organic, flowing shapes between sections
- NOT hard lines, but visual breathing room
- Colors: Soft variations of primary palette

### 2.2 Typography
- **Headlines:** Bold, modern sans-serif (similar feel to 1j1m)
  - Large, confident sizing for hero
  - Clear hierarchy (H1 > H2 > H3)
  
- **Body Text:** Clean, readable sans-serif
  - Minimum 16px for accessibility
  - Line height 1.6 for comfortable reading
  
- **Special Text:** "Fonce, tu en es capable!" style
  - Hand-written feel OR bold italic treatment
  - Stands out visually from other text

### 2.3 Image Treatment

#### **Circle Crops**
- Hero image: Large circle on right side (like 1j1m)
- Consider pen-drawn edge effect (imperfect circle, hand-drawn feel)
- Alternative: Use mask with subtle pen stroke outline

#### **Image Types by Section:**
- **Abstract/Conceptual:** For program explanations, statistics
- **Real Photos:** For founder stories, testimonials (when available)
- **Placeholder:** Random stock photos for now, replaced with real photos later

#### **Photo Style:**
- Natural, warm lighting
- Candid moments > posed portraits
- Diverse representation
- Avoid overly corporate/stock-photo feel

## 6. Animation & Interaction Guidelines

### 6.1 Scroll-Based Animations

**Entrance Animations:**
- **Fade in + slide up** for text blocks
- **Scale/zoom in** for stats/numbers
- **Draw/write effect** for pen line elements
- Stagger timing for multiple elements (don't animate everything at once)

**Scroll Triggers:**
- Animations trigger when element is 20-30% in viewport
- Smooth, natural timing (0.6-0.8s duration)
- Easing: ease-out or cubic-bezier for organic feel

**Pen Line Animation:**
- SVG path animation (stroke-dasharray technique)
- Follows user scroll position
- Connects key sections or milestones
- Subtle, not distracting

### 6.2 Hover States

**Buttons:**
- Slight scale (1.05x)
- Shadow depth increase
- Subtle color shift
- Smooth transition (0.3s)

**Images:**
- Slight zoom or parallax effect
- No harsh movements

**Timeline Elements:**
- Highlight on hover
- Cursor changes to pointer for clickable items

### 6.3 Interactive Elements

**Timeline Expansion (Programme page):**
- Smooth height transition
- Fade in content
- Rotate arrow icon (chevron down → up)
- Accordion behavior (one open at a time, or multiple?)

**Number Counters (stats):**
- Animate from 0 to final number
- Trigger on scroll into view
- Fast but readable speed

### 6.4 Performance Notes
- Use CSS transforms (translate, scale) over position changes
- Optimize SVG paths
- Lazy load images below fold
- Smooth scroll on anchor links

## 7. Content Requirements

### 7.1 Copy Tone & Voice

**Characteristics:**
- **Warm & encouraging** (not corporate or stiff)
- **Confident but humble** (movement, not institution)
- **Direct & clear** (avoid jargon)
- **Youth-oriented** (relatable to lycéens)
- **Motivational** (inspire action)

**Key Phrases to Use:**
- "Fonce, tu en es capable !"
- "Propulsez votre avenir"
- "Un mouvement qui prend de l'ampleur"
- "100% gratuit • 100% à distance"
- "Rejoignez le mouvement"

**Avoid:**
- Overly formal language
- Bureaucratic terms
- Elitist framing ("only the best")
- Corporate speak

### 7.2 SEO Considerations (Basic)

**Meta Title:**
> Propulse | Mentorat Gratuit vers les Grandes Écoles

**Meta Description:**
> Accompagnement gratuit et personnalisé pour lycéens vers les Grandes Écoles. 50+ mentors d'HEC, EDHEC, Sciences Po, Polytechnique. Rejoignez la cohorte 2025 !

**Keywords:**
- mentorat lycéens grandes écoles
- accompagnement gratuit prépa
- égalité des chances éducation
- orientation grandes écoles
- classe préparatoire

### 7.3 Accessibility

**Must-haves:**
- Alt text for all images
- Proper heading hierarchy (H1 → H2 → H3)
- Sufficient color contrast (WCAG AA minimum)
- Keyboard navigation support
- Focus states on interactive elements
- Readable font sizes (minimum 16px body)

## 8. Technical Considerations

### 8.1 Platform/Framework
- **No specific tech stack required** (developer's choice)
- Modern front-end framework recommended (React, Vue, Next.js)
- Static site generation for performance

### 8.2 Responsive Design
- **Mobile-first approach**
- Breakpoints: Mobile (320px+), Tablet (768px+), Desktop (1024px+)
- **Hero:** Image moves below text on mobile
- **3 CTAs:** Stack vertically on mobile
- **Timeline:** Vertical on all screen sizes, simplified on mobile

### 8.3 Performance Targets
- **First Contentful Paint:** < 1.5s
- **Largest Contentful Paint:** < 2.5s
- **Time to Interactive:** < 3.5s
- Lighthouse score: 90+ (Performance, Accessibility)

### 8.4 Browser Support
- Modern browsers (Chrome, Firefox, Safari, Edge)
- Last 2 versions
- Graceful degradation for older browsers
